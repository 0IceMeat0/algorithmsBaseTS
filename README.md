# algorithmsBaseTS

Базовая коллекция алгоритмов на TypeScript с акцентом на читаемость и практическое применение.

Здесь собраны фундаментальные подходы, объясняющие, **почему и когда стоит использовать** тот или иной алгоритм. Репозиторий подходит как для обучения, так и для периодического освежения базовых структур и паттернов.
